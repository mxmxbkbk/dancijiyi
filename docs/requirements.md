## 1. 产品概述

### 1.1 一句话定位

面向英语学习者的离线优先单词记忆 App：用间隔重复把「记不住」变成「忘不掉」，并配套桌面小组件随时复习。

### 1.2 目标

- 让用户用最低操作成本建立自己的单词本。
- 用「记忆阶段 + 下次复习时间」驱动每日复习，而不是无限翻列表。
- 通过桌面小组件把「今天要复习什么」放到用户眼前。
- 数据完全本地保存，不依赖账号与网络。

### 1.3 本期范围

本期（v0.4）交付：

- 单词基础 CRUD：新增、列表查询、详情查看、编辑、删除、手动掌握。
- 列表页接入 Room `Flow`，支持全部 / 待复习 / 已掌握三种本地筛选。
- 详情页按 `wordId` 订阅单词，修改/删除/掌握状态持久化到 Room。
- 基础的数据库异常捕获与页面 Snackbar 提示。
- 保留导入、复习页面 UI 骨架，不实现其业务逻辑。
- 需求文档、数据模型与 Room schema。

### 1.4 非目标

- 不实现词库导入解析、艾宾浩斯/SM-2 复习调度、统计与小组件真实数据。
- 不接入账号、云同步、支付、社交。
- 不实现搜索与标签分类。
- 小组件本期仍为静态示例，真实数据接入在后续迭代完成。

## 2. 用户角色

### 2.1 角色定义

| 角色 | 典型用户 | 核心诉求 | 主要场景 |
| --- | --- | --- | --- |
| 学习者（核心） | 大学生、英语自学者 | 快速记词、按计划复习、看到学习进度 | 每天打开 App 复习到期单词 |
| 备考者 | 四六级、考研、雅思托福备考者 | 批量导入词库、按考试范围高强度复习 | 导入词表后每天刷待复习队列 |
| 词库维护者 | 喜欢整理词库的进阶用户 | 去重、修正释义、管理大量单词 | 导入 CSV/TXT、编辑释义、删除错词 |
| 桌面速览者 | 希望少打开 App 的用户 | 在桌面直接看到今日任务和一张单词卡 | 从桌面小组件进入复习 |

> 一个用户可以同时具备多个角色，不设独立账号体系。

### 2.2 角色故事与权限

- **学习者**：可以新增、查看、编辑、删除自己的单词；可以开始复习并自评；可以标记掌握。
- **备考者**：在 learner 权限基础上，可以批量导入词库；导入时需要看到成功、重复、失败数量。
- **词库维护者**：可以编辑单词与释义、删除单词；重复单词默认跳过，不静默覆盖。
- **桌面速览者**：只读查看待复习数量和今日单词；点击后进入 App 对应页面，不在小组件内直接修改数据。

### 3.3 首页 · 单词列表

- 默认按 `addedAt DESC` 排序，最近添加的在前。
- 列表项展示：单词、释义（最多一行）、记忆阶段标签、到期状态（今天到期 / 已逾期）。
- 顶部展示统计：总计、待复习、已掌握。
- 搜索同时匹配 `word` 与 `meaning`，不区分大小写。
- 筛选：
  - 全部：所有单词。
  - 待复习：`mastered = false AND reviewAt <= now`。
  - 已掌握：`mastered = true`。
- 空状态区分「没有任何单词」与「筛选结果为空」，并提供新增/导入入口。
- 点击列表项进入单词详情；提供新增单词 FAB。
- 数据变化通过 Room `Flow` 自动刷新，不手动重建列表。

### 3.4 单词详情

- 展示全部字段：单词、释义、添加时间、下次复习时间、记忆阶段、是否掌握。
- 时间以本地时区展示，底层存储 epoch millis。
- 支持编辑单词/释义；保存时校验非空。
- 支持标记/取消掌握。标记掌握后不再进入待复习队列。
- 支持删除，删除前二次确认。
- 提供「开始复习」入口，进入复习测试页并从当前单词开始（若未到期，允许提前复习）。

### 3.5 导入词库

- 支持两种输入：
  - 粘贴文本：每行 `单词,释义`。
  - 选择文件：`.csv` / `.txt`，UTF-8 优先。
- 解析规则：
  - 忽略空行与首尾空格。
  - 以第一个逗号分隔单词与释义；释义中允许出现逗号。
  - 单词、释义均为空或缺失的行标记为错误。
- 导入前预览：
  - 有效条数。
  - 重复条数（与库内已有单词大小写不敏感重复，或本次文件内重复）。
  - 错误条数与行号、原因。
- 默认策略：重复项跳过，不覆盖已有释义；错误项不阻塞其他行。
- 导入完成后展示成功、跳过、失败数量；导入操作应在事务中完成，避免部分写入。
- 单词入库前 `trim`；大小写不敏感唯一由数据库索引兜底。

### 3.6 复习测试

- 进入页面时读取到期队列：`mastered = false AND reviewAt <= now`，按 `reviewAt` 升序。
- 单张卡片流程：
  1. 显示单词，先不显示释义。
  2. 用户点击「显示释义」。
  3. 用户自评：不认识 / 模糊 / 认识。
  4. 系统更新 `memoryStage`、`reviewAt`，必要时更新 `mastered`。
  5. 进入下一张；队列为空时展示会话总结。
- 自评的业务含义（具体间隔算法后续实现）：
  - 不认识：阶段回退或停留在较低阶段，较短间隔后再次出现。
  - 模糊：阶段不升或小幅提升，中等间隔。
  - 认识：阶段 +1，较长间隔；达到阶段 5 后由用户或策略标记掌握。
- 中途退出不丢数据：每张卡的自评立即写入。
- 已掌握单词不进入队列；用户可在详情页取消掌握后重新加入。

### 3.7 辅助功能（后续）

- 学习统计：每日复习数、掌握率、连续打卡。
- 设置：深色模式、每日新词上限、提醒时间。
- 备份：导出/导入本地数据库或 JSON。

## 4. 伴生桌面小组件功能清单

小组件属于 P1 能力，作为主 App 的「桌面速览入口」，不替代主界面。

| 编号 | 功能 | 优先级 | 说明 |
| --- | --- | --- | --- |
| W-01 | 今日待复习数量 | P1 | 展示 `mastered = false AND reviewAt <= now` 的数量 |
| W-02 | 今日单词卡片 | P1 | 展示一个单词与释义；可配置是否隐藏释义 |
| W-03 | 点击跳转 | P1 | 点击数字进入复习页；点击单词进入详情或复习页 |
| W-04 | 空状态与刷新 | P1 | 无单词时显示引导；数据变化后主动刷新 |
| W-05 | 尺寸与深色模式 | P2 | 支持 2x1、4x2 等尺寸；跟随系统深色模式 |
| W-06 | 隐私模式 | P2 | 桌面隐藏释义，点击后再显示 |

### 4.1 展示形态

- **2x1 小尺寸**：今日待复习数量 + 「去复习」。
- **4x2 中尺寸**：单词、释义、待复习数量、进入复习按钮。
- **空状态**：暂无单词时显示「添加第一个单词」。
- 文案使用中文，单词本身保持用户输入原样。

### 4.2 数据与刷新约束

- 小组件运行在独立进程/RemoteViews 环境，**不能直接访问 App 的 Room 实例**。
- 后续通过 `ContentProvider`（或 DataStore + 主动推送）向小组件暴露只读的「今日单词 + 待复习数」。
- 数据变更触发点：新增/编辑/删除单词、复习自评、标记掌握、导入完成。
- 系统 `updatePeriodMillis` 最短约 30 分钟；不能依赖它做秒级刷新，关键更新由 App 主动调用 `AppWidgetManager`。
- 设备重启后由 `ACTION_APPWIDGET_UPDATE` 恢复展示；无网络也能工作。

## 6. 关键业务规则

1. **唯一性**：`word` 在数据库层大小写不敏感唯一；导入重复默认跳过，不覆盖已有释义。
2. **非空**：单词与释义均不能为空白；入库前去除首尾空格。
3. **时间**：所有时间字段使用 epoch millis；展示时转换为本地时区。
4. **阶段**：`memoryStage` 取值 0..5，表示记忆深度；数据库不强制范围，由业务层校验。
5. **掌握**：`mastered` 是独立业务标记；为 true 时不进入待复习队列，与阶段值不强制联动。
6. **复习时间**：`reviewAt` 表示下一次复习时间；新词默认立即到期，便于直接进入首次复习。
7. **不可变字段**：`addedAt` 创建后不随编辑/复习改变。
8. **离线优先**：所有核心功能不依赖网络；无账号体系。

## 7. 非功能需求

- **性能**：1 万词以内列表滚动流畅；后续使用 Paging 3 分页；查询走索引。
- **线程**：Room 查询使用 `Flow` / suspend，不阻塞主线程。
- **可靠性**：导入使用事务；复习自评即时落库；异常时不让数据库处于半写入状态。
- **隐私**：单词数据仅保存在本机；不上传服务器。
- **可访问性**：支持系统字体缩放、深色模式、TalkBack 可读标签。
- **兼容性**：minSdk 26，targetSdk / compileSdk 37。
- **可维护性**：数据层与 UI 解耦；通过 Repository 暴露数据；数据库迁移必须保留 schema。
